## 1. 两个"项目"各是什么

| | 龙虾工作台 / MinimaxH3 | Oyama 桌面端（本仓库） |
|---|---|---|
| 性质 | 调研 + 提示词/工作流资产库，**无可运行应用** | 可运行的本地视频工作台应用（Electron + ComfyUI） |
| 主要资产 | H3 本地部署调研文档 5 篇、《四月物语》H3 复刻提示词资产、qwen-image-edit 工作流 JSON×2、prompt-hub 提示词库 13 条（Next.js 独立小应用）、节点图 SVG + Python 脚本 | H3 / LTX / ZImage / FireRed / Audio / PhotoEdit 全工作流、ComfyUI 管理与队列 |

**结论：不存在"代码合并"对象**——你的项目没有应用层代码要融进本仓库，能融合的是资产与知识层。逐模块评估如下。

## 3. 风险与前置

1. **上游覆盖**：本仓库汉化是活跃上游项目的本地修改，上游更新再合并必冲突。需把汉化固化为单一补丁序列，每次 rebase 后跑红线回归（依赖《待优化点清单》P0-1 先落地）。
2. **数据残留**：汉化首轮曾把模型输入选项值译成中文（如 shotSize="远景"），期间产生的旧存档 beat 会空选 → 需一次性归一化（《待优化点清单》P0-2）。
3. **模型前置**：四月物语素材假设本地 H3 模型栈已部署，使用前对照本机 ComfyUI 的 object_info 校验。
4. **文档时效**：部署调研文档与 app 当前模型/节点常量可能漂移，入库时标注版本号。

## 4. 建议执行顺序

- **P0**（立即）：四月物语素材进 app 当中文演示工程——零代码改动，约 2 小时。
- **P1**：部署调研文档汉化入库（0.5 天）+ 红线回归测试落地（《待优化点清单》P0-1）。
- **P2**（挂起）：prompt-hub 入库决策（条目增长后）、Qwen 图像编辑工作区（有真实需求再做）。
